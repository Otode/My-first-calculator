# 🧮 C# Console Calculator

Простой, но надежный консольный калькулятор на C#, созданный с акцентом на безопасную обработку пользовательского ввода и производительность.

---

## 🚀 Особенности (Features)

* **Безопасная валидация ввода:** Использование `float.TryParse` предотвращает падение программы при некорректных данных.
* **Поддержка дробей и знаков:** Автоматическая обработка точек и запятых в разделителях.
* **Управление флагами (CLI Flags):** Быстрый доступ к командам через специальный префикс:
  * `>q` — Мгновенный выход из программы.
  * `>h` — Вызов справки прямо во время ввода чисел.
* **Защита от крашей:** Устойчивость к делению на ноль и пустому вводу (`Enter`).

---

## 🛠️ Технологии

* **Язык:** C# (.NET 8.0 / .NET Framework)
* **Парадигма:** Процедурный подход, DRY-методология.
